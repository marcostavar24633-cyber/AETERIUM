# SONORA — QA checklist

## Automated checks

- [ ] Главная: заголовок, навигация, featured карточки.
- [ ] Все 8 категорий загружают товары.
- [ ] Каталог: 64 demo позиции, поиск, фильтры, сортировка.
- [ ] Карточка товара загружается по slug.
- [ ] Корзина: добавление, увеличение/уменьшение количества, удаление, итог.
- [ ] Избранное сохраняет список в localStorage.
- [ ] Demo checkout не отправляет данные и не создаёт заказ.
- [ ] Мобильное меню доступно с клавиатуры и touch.
- [ ] Нет горизонтального overflow при 320, 390, 768, 1440 px.
- [ ] Нет необработанных JavaScript ошибок и отсутствующих локальных ресурсов.
- [ ] JSON каталога валиден; каждая позиция имеет demo=true.
- [ ] robots.txt и sitemap.xml содержат только актуальные URL SONORA.

## Ручная проверка перед публикацией

- [ ] Проверить на реальных iOS/Android устройствах.
- [ ] Проверить клавиатурную навигацию и фокус.
- [ ] Проверить контраст и prefers-reduced-motion.
- [ ] Проверить все тексты, изображения и SEO вручную.
- [ ] Выполнить Lighthouse и проверить Core Web Vitals.
- [ ] Проверить URL после публикации на выбранном хостинге.

## Ограничения

Текущая версия — прототип. Товары, бренды, цены и характеристики вымышлены. Фотографии изделий не добавлены. Checkout не создаёт заказ, не передаёт данные и не принимает оплату.
