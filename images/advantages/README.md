# AETERIUM — интерьерные рендеры для шести карточек

Подготовлены шесть отдельных изображений в формате JPG. Они соответствуют карточкам преимуществ сайта по порядку.

Загрузите шесть JPG-файлов из архива в эту папку:

- `01-multilevel-light.jpg`
- `02-light-scenarios.jpg`
- `03-accent-details.jpg`
- `04-comfort-rest.jpg`
- `05-smart-control.jpg`
- `06-energy-efficiency.jpg`

Рекомендуемый способ: распаковать архив, открыть папку `images/advantages` в GitHub, выбрать **Add file → Upload files**, добавить шесть JPG и нажать **Commit changes**.

После загрузки изображения можно подключить к карточкам в `index.html`. Пока файлы не добавлены в репозиторий, сайт продолжает использовать текущие изображения.
