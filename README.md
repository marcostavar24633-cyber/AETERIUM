# AETERIUM — Архитектура света

Премиальный одностраничный сайт вымышленного бренда интеллектуальных световых систем и архитектурных инсталляций.

**Слоган:** «Свет, который формирует пространство».

## Состав проекта

- `index.html` — сайт целиком: HTML, CSS и JavaScript в одном файле.
- Адаптивная вёрстка для мобильных устройств и больших экранов.
- Тёмная и светлая темы.
- Три-панельная структура навигации: основная навигация и орбитальное меню.
- Процедурный WebGL-фон на Three.js с CSS fallback.
- Пять процедурных сцен с автоматическим переходом.
- Поддержка собственных изображений для сцен.
- Анимации появления блоков и поддержка `prefers-reduced-motion`.
- Демонстрационная форма без отправки и сохранения персональных данных.

## Запуск

Скачайте `index.html` и откройте его в современном браузере. Сборка, Node.js и сервер для локального просмотра не требуются.

Three.js и шрифты загружаются с CDN, поэтому для полного визуального эффекта требуется подключение к интернету. Если CDN недоступен, предусмотрен статический фон.

## Подключение собственных изображений

В начале JavaScript в `index.html` найдите:

```js
const SCENE_IMAGES = ['', '', '', '', ''];
```

Укажите пути к пяти изображениям, например:

```js
const SCENE_IMAGES = [
  'images/scene-1.jpg',
  'images/scene-2.jpg',
  'images/scene-3.jpg',
  'images/scene-4.jpg',
  'images/scene-5.jpg'
];
```

Создайте папку `images` рядом с `index.html` и положите в неё изображения. Пустые значения оставляют процедурную сцену без фотографии.

## Важно

Форма обратной связи работает только как демонстрация интерфейса: данные не отправляются и не сохраняются. Для приёма заявок потребуется отдельно подключить выбранный канал обработки.
