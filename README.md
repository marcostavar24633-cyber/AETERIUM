# AETERIUM JEWELRY HOUSE

Премиальный многостраничный демонстрационный интернет-магазин ювелирных изделий.

## Статус проекта

Проект находится в разработке на ветке `jewelry-rebuild`. Основная ветка `main` пока сохраняет исходную версию AETERIUM, поэтому новая концепция не публикуется вместо неё до прохождения проверок.

## Структура

- `index.html` — главная витрина ювелирного дома.
- `catalog.html` — каталог с поиском, фильтрами и сортировкой.
- `product.html?slug=...` — самостоятельная карточка конкретного товара.
- `cart.html` — демонстрационная корзина.
- `favorites.html` — избранные товары.
- `data/products.json` — единый источник данных каталога.
- `assets/jewelry.css` — дизайн-система.
- `assets/jewelry.js` — общие клиентские механики.

## Демонстрационный каталог

Подготовлено 120 демонстрационных позиций в 14 категориях. Цены, наличие, описания и характеристики условные. Это не реальные предложения о продаже. Фотографии пока представлены нейтральными визуальными заглушками.

## Запуск локально

Откройте проект через локальный HTTP-сервер (например, `python -m http.server 8000`), затем перейдите на `http://localhost:8000`. Не открывайте страницы через `file://`: каталог загружается через fetch из JSON.

## Ограничения

- Корзина и избранное сохраняются только в localStorage текущего браузера.
- Реальная регистрация, серверное управление товарами, остатками, заказами и оплата не подключены.
- Перед коммерческим запуском необходимо заменить демонстрационные товары, изображения, цены и характеристики на проверенные данные.
- Для обработки заказов и платежей требуется безопасная серверная часть и юридически корректные документы.
- Внутренние ссылки рассчитаны на размещение проекта в корне GitHub Pages. Для публикации в подпапке репозитория потребуется настроить base path.

## Проверка

Браузерные проверки выполняются GitHub Actions workflow `.github/workflows/browser-qa.yml`.
