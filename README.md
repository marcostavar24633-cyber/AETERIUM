# AETERIUM — Архитектура света

Премиальный одностраничный сайт вымышленного бренда интеллектуальных световых систем и архитектурных инсталляций.

**Слоган:** «Свет, который формирует пространство».

## Состав проекта

- `index.html` — весь сайт в одном файле: HTML, CSS и JavaScript.
- Развёрнутые описания трёх направлений, инженерного подхода и этапов сотрудничества.
- Раздел FAQ с ответами о подготовке проекта, интеграции, стоимости и сроках.
- Контент оформлен как концепт вымышленной световой студии, а не подтверждённый каталог реальных услуг.
- Адаптивная компоновка для мобильных устройств, планшетов и широких экранов.
- Тёмная и светлая темы с сохранением выбора в браузере.
- Основная навигация и отдельное орбитальное меню.
- Процедурный WebGL-фон на Three.js с CSS fallback.
- Пять процедурных визуальных сцен с плавным переходом.
- Опциональная загрузка пяти локальных изображений для WebGL-сцен.
- Анимации появления блоков и поддержка `prefers-reduced-motion`.
- Демонстрационная форма без отправки и сохранения персональных данных.

## Запуск

Скачайте `index.html` и откройте его в современном браузере. Сборка и Node.js не требуются.

Three.js и шрифты загружаются с CDN, поэтому для полного эффекта нужно подключение к интернету. При недоступности WebGL или библиотеки предусмотрен статический CSS-фон.

## Собственные изображения

В JavaScript найдите массив:

```js
const SCENE_IMAGES = ['', '', '', '', ''];
```

Укажите пути к файлам, например:

```js
const SCENE_IMAGES = [
  'images/scene-1.jpg',
  'images/scene-2.jpg',
  'images/scene-3.jpg',
  'images/scene-4.jpg',
  'images/scene-5.jpg'
];
```

Папка `images` должна находиться рядом с `index.html`. Пустые строки оставляют соответствующие сцены процедурными.

## Ограничения текущей версии

- Форма обратной связи демонстрационная: она не передаёт заявки. Для реального приёма обращений потребуется подключить CRM, почту или другой выбранный сервис.
- Внешний вид и работу WebGL нужно дополнительно проверить в целевых браузерах и на реальных мобильных устройствах.
- Проект не содержит серверной части и не сохраняет пользовательские данные.
