# AETERIUM JEWELRY HOUSE

Премиальный многостраничный демонстрационный интернет-магазин ювелирных изделий.

## Статус разработки

Новая концепция развивается в ветке `jewelry-rebuild`. Основная ветка `main` не заменена и не изменена этой работой.

## Страницы и функции

- `index.html` — главная витрина и ссылки на коллекции.
- `catalog.html` — каталог: поиск, фильтры, сортировка.
- 14 отдельных SEO-страниц категорий: `rings.html`, `earrings.html`, `engagement-rings.html` и другие.
- `product.html?slug=...` — карточка отдельного товара.
- `cart.html` — корзина с изменением количества и удалением позиций.
- `favorites.html` — избранное.
- `checkout.html` — только демонстрация интерфейса оформления; ничего не отправляет и не создаёт.
- Информационные страницы: about, delivery, payment, returns, warranty, contacts, faq, collections, gifts, journal.
- `robots.txt` и `sitemap.xml` — базовая SEO-инфраструктура.
- `data/products.json` — единый каталог из 120 демонстрационных товаров в 14 категориях.

## Демонстрационные данные

Все товары, цены, наличие, описания и характеристики условные. Фотографии изделий ещё не добавлены. Не использовать данные как коммерческое предложение без замены и проверки.

## Запуск

Откройте проект через HTTP-сервер, например:

```bash
python -m http.server 8000
```

Затем перейдите на `http://localhost:8000`. Не открывайте страницы через `file://`, поскольку каталог загружается через fetch из JSON.

## Ограничения и безопасность

- Корзина и избранное сохраняются только в localStorage браузера.
- Мобильное меню и каталог работают на клиентской стороне.
- Checkout — исключительно локальная демонстрация. Форма не отправляет персональные данные, не создаёт заказ и не принимает оплату.
- Реальные остатки, учёт пользователей, серверное управление заказами, уведомления и платежи не подключены.
- Для запуска продаж потребуется защищённая серверная часть, реальный каталог, юридические документы, настройка доставки и платёжного провайдера.
- Информационные страницы содержат нейтральные заглушки там, где реальные данные владельца ещё не предоставлены.

## QA

GitHub Actions workflow `.github/workflows/browser-qa.yml` запускает Playwright Chromium и проверяет главную, категории, каталог, карточку товара, корзину, checkout demo, мобильное меню, ширины 390/320 px и ошибки JavaScript.
