# SONORA — AUDIO CULTURE

Премиальная демонстрационная концепция интернет-магазина аудиотехники и музыкальной культуры.

## Важно

SONORA, бренды, модели, цены, характеристики, контакты и коммерческие условия в этой ветке придуманы для прототипа. Это не действующий магазин и не реальные предложения о продаже. Изображения товаров пока представлены абстрактными графическими заглушками.

## Что реализовано

- Главная страница с новым позиционированием SONORA.
- Единый каталог из 64 вымышленных демонстрационных товаров в 8 категориях.
- Поиск, фильтры по категории/бренду/типу, сортировка.
- Отдельные SEO-страницы категорий.
- Карточка товара по slug.
- Корзина с изменением количества и удалением.
- Избранное.
- Demo checkout: форма не отправляет персональные данные, заказ не создаётся, оплата не производится.
- Адаптивное мобильное меню.
- Информационные страницы о проекте, доставке, оплате, возврате, контактах и FAQ.
- Журнал как будущий редакционный раздел.
- robots.txt и sitemap.xml.
- Полное бизнес-, маркетинговое, UX-, SEO-, визуальное и техническое ТЗ в `docs/SONORA-MASTER-BRIEF.md`.

## Архитектура

- `data/sonora-products.json` — каталог демонстрационных позиций.
- `assets/sonora.css` — дизайн-система.
- `assets/sonora.js` — общие механики и localStorage.
- `assets/sonora-catalog.js` — поиск и фильтры.
- `assets/sonora-product.js` — карточка товара.
- `assets/sonora-cart.js` — корзина.
- `assets/sonora-favorites.js` — избранное.
- `assets/sonora-checkout.js` — локальная демонстрационная форма.

## Локальный запуск

Из корня проекта:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. Не используйте `file://`: JSON-каталог загружается через fetch.

## Ограничения перед реальным запуском

1. Заменить все демо-товары на подтверждённый ассортимент.
2. Добавить лицензированные фотографии и точные характеристики производителя.
3. Подтвердить бренды, цены, наличие, поставщиков и условия продаж.
4. Утвердить юридические документы, доставку, возврат и контакты.
5. Реализовать backend, безопасное оформление заказов, обработку персональных данных и платёжный провайдер.
6. Настроить реальные домен, аналитику, Search Console и проверить SEO после публикации.

## QA

GitHub Actions workflow `.github/workflows/browser-qa.yml` запускает Playwright Chromium для проверки главной, категорий, 64 товаров, фильтров, карточки, корзины, demo checkout, мобильного меню и overflow на мобильных разрешениях.
